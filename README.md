# RelayDesk

Приложение для Windows: управление sing-box и zapret, импорт VPN-профилей и настройка маршрутов по приложениям и адресам.

## Сборка

Для сборки исходников нужен .NET 9 SDK:

```powershell
dotnet build .\RelayDesk\RelayDesk.csproj -c Release
```

Сборка установщика описана в [инструкции](RelayDesk/installer/README.md). Исходники приложения находятся в папке [RelayDesk](RelayDesk).

Профили, пароли, журналы и скачанные ядра в репозиторий не включены. Ядра устанавливаются из приложения после подтверждения пользователя.
