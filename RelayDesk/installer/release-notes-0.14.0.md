RelayDesk 0.14.0

Установщик включает sing-box 1.14.3, Xray 26.3.27, mihomo 1.19.32 и Flowseal/zapret 1.10.3. Архивы получены из официальных релизов; при сборке проверяется SHA-256. Вместе с ядрами устанавливаются DLL, WinDivert, данные и лицензии из пакетов.

При первом запуске пути к встроенным ядрам заполняются автоматически. Для Flowseal выбирается начальная стратегия; её работоспособность зависит от подключения и проверяется отдельно. Интернет для установки ядер не нужен. Профили и подписки импортируются пользователем.

Существующие рабочие пути к ядрам сохраняются. Установщик не включает личные профили и ссылки подписок. Обновления компонентов по-прежнему требуют подтверждения.
