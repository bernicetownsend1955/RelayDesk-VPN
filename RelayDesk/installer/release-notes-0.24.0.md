# RelayDesk 0.24.0

- Репозиторий RelayDesk закреплён: bernicetownsend1955/RelayDesk-VPN. Изменить его в настройках нельзя.
- Обновления RelayDesk скачиваются и проверяются автоматически. Установка выполняется при закрытии или следующем запуске, затем приложение открывается снова.
- Добавлено автоматическое обновление Xray и mihomo вместе с sing-box и Flowseal zapret из официальных репозиториев.
- Пакеты ядер готовятся отдельно от работающих файлов и применяются при следующем запуске. Предыдущие файлы сохраняются.
- Перед переключением проверяются SHA-256 и совместимость конфигураций. Повреждённый пакет не применяется.

Текущее VPN-подключение не прерывается во время загрузки. Windows может запросить права администратора для установки. Для Discord с зависанием DTLS на прямом маршруте сохраняйте голос через VPN.
