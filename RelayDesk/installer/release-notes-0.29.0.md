# RelayDesk 0.29.0

- Режим покоя включается тумблером вместо галочки; сохранённая настройка остаётся прежней.
- Добавлен отдельный оверлей поверх окон: название активного VPN, входящая и исходящая скорость в Мбит/с. По умолчанию выключен.
- Оверлей можно перетаскивать, размещать в любом углу, менять непрозрачность и размер текста. Положение и оформление сохраняются. Оверлей остаётся при сворачивании главного окна и закрывается вместе с программой.
- Учитывается только трафик VPN RelayDesk. sing-box и mihomo используют счётчики активных соединений с опросом каждые 500 мс; короткие соединения между замерами могут быть пропущены. Xray использует накопительные счётчики VPN-выходов. При отсутствии данных показывается прочерк.
