Запусти `RelayDesk-Setup-0.14.0-x64.exe`, подтверди запрос Windows и выбери папку установки. По умолчанию используется `C:\Program Files\RelayDesk`. Среда .NET и ядра sing-box, Xray, mihomo, Flowseal/zapret входят в пакет.

При первом запуске приложение проверит встроенные файлы и заполнит пути к ядрам. Докачивать ядра не требуется. Импортируй профиль или подписку; стратегию zapret проверь на своём подключении. Рабочие внешние ядра, уже выбранные в настройках, сохраняются. Обновления загружаются только после подтверждения.

При установке на том же компьютере приложение использует существующие профили из `%LOCALAPPDATA%\RelayDesk`. Удаление через настройки Windows удаляет приложение, сохраняя профили, настройки и скачанные ядра в данных пользователя. Для переноса на другой компьютер импортируй профиль отдельно: установщик не содержит пользовательских данных.

Повторная установка новой версии обновляет ту же программу. Перед установкой или удалением закрой RelayDesk через «Выход». Установщик не завершает рабочее VPN-подключение автоматически.

Сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Installer.ps1`. Нужны .NET SDK 9 и Inno Setup 6; путь к `ISCC.exe` передаётся параметром `-Compiler`. Результат сохраняется в `output`. Параметр `-TestBuild` создаёт отдельный тестовый установщик; `Test-Installer.ps1` проверяет его установку в Program Files, запуск интерфейса и удаление, не заменяя основную программу.

Установщик не подписан сертификатом издателя.

Автозапуск: открой «Настройки → Запуск вместе с Windows», выбери компоненты и профиль VPN, затем нажми «Сохранить автозапуск». Для текущей учётной записи создаётся задача Планировщика с повышенными правами, которая запускает приложение через 15 секунд после входа в Windows. Пароль не сохраняется. По умолчанию автозапуск выключен. Обычный запуск ярлыком не включает соединения автоматически; автоподключение выполняется только при запуске задачей Windows. «Остановить всё» отменяет ожидающее подключение. При удалении приложения удаляются задачи, указывающие на его установленный EXE.

Версии и SHA-256 архивов закреплены в `cores.lock.json`. `Prepare-Cores.ps1` получает официальные пакеты, проверяет архивы и включает их зависимости и лицензии в сборку. Личные профили и настройки не используются при упаковке. Для первой сборки нужен интернет; установщику интернет для развёртывания ядер не требуется.
