RelayDesk 0.16.0

- Вкладка «Соединения» поддерживает sing-box, mihomo и Xray. Для mihomo добавляется защищённый локальный Clash API; Xray показывает реальные выбранные выходы по событиям access-журнала.
- Данные Xray отображаются как история за последние 3 минуты: ядро не сообщает процесс, объём трафика и момент закрытия соединения. Записи access-журнала остаются в памяти приложения и не попадают в журнал отправки на ВДС.
- Добавлен блок «Задержка серверов (TCP)»: проверка серверов выбранной группы, результаты по профилям, сортировка по задержке и отмена. Работающий VPN не останавливается; проверка использует текущие маршруты Windows.
- Сохраняется исправление запуска Xray вместе с zapret и новая страница профилей из 0.15.0. Для отображения новых данных нужно запустить профиль в этой версии приложения.

Ядра sing-box, Xray, mihomo и Flowseal/zapret включены в установщик.
