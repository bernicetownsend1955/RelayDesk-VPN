# RelayDesk 0.30.1

- Перетащи EXE, ярлык приложения или ссылку сайта в любую вкладку основного окна. Откроется выбор: через VPN, через zapret или напрямую.
- Если правило уже существует, изменяется оно, без создания дубликата. Правила сохраняются для всех профилей и групп.
- Можно сохранить правило на следующее подключение или сразу применить к работающему VPN. Отмена оставляет настройки прежними.
- Для окна с правами администратора перетаскивание принимает отдельный процесс с обычными правами Windows. EXE и ярлыки при добавлении не запускаются, сайты не открываются.

Для правил EXE нужен sing-box с TUN. Обработка zapret зависит от настроенного фильтра; выбор маршрута не заменяет включение zapret.
