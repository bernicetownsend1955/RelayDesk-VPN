# RelayDesk 0.26.1

- Исправлена ошибка запуска TUN «set ipv4 address: The object already exists» при занятом адресе 172.19.0.1.
- Для TUN выбирается свободная подсеть с учётом адресов интерфейсов и маршрутов Windows.
- Интерфейсы RelayDesk получают отдельные имена. Чужие интерфейсы не удаляются.
- В журнале показываются имя и адрес TUN RelayDesk.
- Старые профили подписок с DNS по умолчанию 1.1.1.1 используют системный DNS в конфигурации запуска. Другие DNS-адреса сохраняются.
- Исходные JSON, общие правила и параметры подписок сохраняются.
