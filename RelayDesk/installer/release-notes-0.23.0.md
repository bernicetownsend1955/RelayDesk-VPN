RelayDesk 0.23.0

- Подписки HTTPS и Happ с предпросмотром импорта, группы профилей и поиск.
- Отдельная страница профилей с TCP-проверкой задержки серверов.
- Ядра sing-box, Xray, mihomo и Flowseal/zapret включены в установщик.
- Во вкладке «Соединения» доступны текущие соединения sing-box/mihomo и история маршрутов Xray. Для Xray можно задавать правила по домену и IP; журнал не определяет приложение.
- Запоминается последний успешно подключённый сервер. Для разделения Discord полный JSON sing-box получает TUN в рабочей копии; исходная конфигурация сохраняется.
- Добавлен диагностический переключатель обработки голосового UDP. Из голосовых профилей убран QUIC-шаблон, содержимое STUN-шаблона проверяется перед использованием.
- Выпуски по тегам собираются и публикуются через GitHub Actions.

Известное ограничение: прямой голос Discord через zapret всё ещё может зависать на DTLS. Диагностический переключатель не является подтверждённым исправлением. Проверенный рабочий вариант — направлять Discord через VPN; zapret может одновременно работать для другого трафика.
