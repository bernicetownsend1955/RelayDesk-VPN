RelayDesk 0.13.0

- Импорт HTTPS-подписок и ссылок happ://add/https://… через буфер обмена или кнопку «Подписки / обновить».
- Предпросмотр серверов перед импортом, распознавание Base64-списков и списков JSON, выбор группы для новых серверов.
- Сохранение адреса подписки и ручное обновление. Существующие правила маршрутизации, TUN и принадлежность профилей к группам сохраняются; обновление не переподключает работающий VPN.
- Постоянный идентификатор устройства для провайдеров с HWID. Идентификатор не меняется при обновлении подписки. Ошибки лимита устройств и заглушки провайдера отображаются отдельно.
- VLESS с параметрами Xray (spiderX, gRPC multi, WebSocket heartbeat, XHTTP) импортируется в JSON для Xray с сохранением параметров. Ядро каждого профиля указано в предпросмотре; для Xray нужен настроенный путь к его EXE, TUN sing-box к таким профилям не применяется.

Неподдерживаемые записи показываются в предпросмотре как пропущенные. Расширенные ссылки Hysteria2 пока не импортируются. Параметры маршрутизации Happ автоматически не переносятся. Отсутствующие в новом ответе серверы автоматически не удаляются.
