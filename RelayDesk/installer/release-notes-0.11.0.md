RelayDesk 0.11.0

- В окне маршрута соединения появился отдельный пункт «Через zapret». Он выводит выбранный трафик из VPN и добавляет фильтр в winws при совместной работе VPN и zapret.
- При выключенном zapret эти правила не меняют исходный маршрут VPN.
- Добавлены группы подписок: создание, переименование, удаление группы без удаления профилей, перенос профилей и фильтр списка. При импорте в выбранную группу новые профили попадают в неё; синхронизация сохраняет прежнюю принадлежность.

Для правила приложения нужен TUN. Winws не фильтрует пакеты по EXE: правило приложения расширяет перехват TCP/UDP и может затрагивать другой прямой трафик. Для адреса используется фильтр домена или IP; произвольные пользовательские --wf-raw не поддерживаются. Применение сохранённых правил переподключает компоненты.
