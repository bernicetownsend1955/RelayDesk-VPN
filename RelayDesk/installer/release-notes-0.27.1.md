# RelayDesk 0.27.1

- TUN, системный прокси и локальный порт теперь общие для всех VPN и групп. При первом запуске они берутся из «Мой VPN».
- Общий режим можно менять в настройках или в параметрах любого профиля. Исходные JSON, серверы и ключи сохраняются.
- Появился раздел «Общий режим подключения». Сохранённые изменения применяются при следующем подключении или по кнопке «Применить правила».
- Установщик автоматически закрывает RelayDesk и восстанавливает подключение после обновления.
