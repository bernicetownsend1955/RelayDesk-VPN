# RelayDesk 0.26.0

- Правила приложений, доменов и IP теперь общие для всех профилей VPN и групп подписок.
- При первом запуске правила из «Мой VPN» переносятся в общий набор. Уникальные правила остальных профилей добавляются; при совпадении сохраняется вариант из «Мой VPN». Перед переносом создаётся резервная копия.
- Изменения из любого профиля видны в остальных. Новые серверы подписок используют тот же набор правил.
- Маршрут через VPN использует выход выбранного сервера, даже если названия выходов различаются.
- Для общих правил приложений sing-box автоматически получает TUN в конфигурации запуска. Исходный JSON сохраняется.
- Xray применяет общие правила доменов и IP; для правил EXE требуется sing-box. При запуске Xray это указано в журнале.
- Сохранение не прерывает подключение. Кнопка «Применить правила» переподключает работающий VPN; остальные используют изменения при следующем подключении.
