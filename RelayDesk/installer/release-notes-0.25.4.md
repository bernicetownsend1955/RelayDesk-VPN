# RelayDesk 0.25.4

- Вкладке «Соединения» возвращён компактный вид. Постоянные поля фильтров убраны, заголовки отображаются без рамок кнопок.
- Щелчок по заголовку сортирует столбец; правая кнопка открывает его фильтр. Фильтры можно сочетать. Активные условия показываются отдельной строкой с кнопкой сброса.
- Панель массовой настройки появляется только после выделения соединений через Ctrl + щелчок. Сохранены предпросмотр правил, объединение повторов и проверка всего пакета перед сохранением.

Профили и исходный JSON сохраняются. Сохранение правил не переподключает работающий профиль автоматически.
