# RelayDesk 0.27.0

- При обновлении установщик автоматически закрывает RelayDesk перед заменой файлов и запускает его после установки.
- Восстанавливаются прежний сервер, включённые VPN и zapret, открытая вкладка и состояние окна.
- Несохранённые поля профиля и JSON переносятся как черновик.
- Встроенное обновление использует то же восстановление подключения.
- Снимок перезапуска одноразовый и не запускает подключение повторно при обычном открытии программы.
