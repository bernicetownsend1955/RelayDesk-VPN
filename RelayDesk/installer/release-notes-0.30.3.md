# RelayDesk 0.30.3

- Добавлена обработка переноса выделенного адреса из адресной строки Яндекс Браузера, когда браузер не передаёт ссылку обычным перетаскиванием Windows. Меню маршрута открывается после отпускания над RelayDesk.
- Если обычная передача ссылки сработала, резервная обработка не открывает второе меню. Esc отменяет жест.
- Добавлены Ctrl+V вне полей ввода и кнопка «Вставить» в разделе приложений. Адрес сайта открывает выбор VPN / zapret / напрямую. Во вкладке профилей Ctrl+V открывает импорт подписки или конфигурации.
- В полях ввода Ctrl+V сохраняет обычную вставку текста. Ссылки протоколов и JSON открываются с предпросмотром; изображение QR-кода можно вставить из буфера.
- Чтение буфера повторяется при кратковременной занятости другим процессом Windows.

Перенос адреса читает только адресный элемент под начальной точкой жеста. Буфер обмена для этого не подменяется. Профили, подписки и сохранённые правила при обновлении сохраняются.
