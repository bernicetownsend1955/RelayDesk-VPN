# RelayDesk 0.25.2

- Автозапуск Windows настраивается в новом интерфейсе: запуск программы, независимое включение VPN и zapret, выбор профиля и сохранение. Перехода в прежнее меню больше нет.
- Настройка профиля, JSON/YAML, ядра, импорт и обновления открываются внутри основной навигации. Вторая боковая панель скрыта. Переходы между формами синхронизируются с выбранным разделом; возврат на главную открывает новую панель подключения.
- Диалоги групп и подписок используют графитовые цвета и кнопки нового интерфейса.
- Подпись версии внизу окна берётся из сборки.
- В README добавлены скриншоты главного экрана, профилей, правил и автозапуска с тестовыми данными.

Профили, подписки, исходные конфигурации и параметры автозапуска сохраняются. Текущее подключение не меняется при открытии настроек.
