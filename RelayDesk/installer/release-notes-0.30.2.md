# RelayDesk 0.30.2

- Исправлен запуск перетаскивания и оверлея при отключённой службе Windows «Вторичный вход в систему». Включать службу или менять настройки Windows не требуется.
- Приёмник EXE, ярлыков и ссылок запускается с обычными правами через контекст Проводника Windows. Основное приложение сохраняет права администратора для TUN и zapret.
- Установщик учитывает новый способ запуска вспомогательных процессов и дожидается их закрытия при обновлении.

Выбор VPN, zapret и прямого подключения работает в прежнем меню. Сохранённые профили, подписки и правила остаются прежними.
