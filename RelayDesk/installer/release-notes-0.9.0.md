- Добавлен запуск RelayDesk при входе в Windows.
- VPN и zapret можно включать автоматически вместе или по отдельности.
- Для VPN выбирается сохранённый профиль; учитывается настройка автовыбора сервера.
- Приложение ждёт появления сетевого интерфейса перед подключением.
- Ручное управление отменяет ожидающее автоматическое подключение.
