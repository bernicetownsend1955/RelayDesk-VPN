RelayDesk проверяет последний опубликованный стабильный релиз GitHub при запуске и каждые 6 часов, если включена общая проверка обновлений. Укажи публичный репозиторий в разделе «Обновления → RelayDesk». Пока поле пустое, проверяются только ядра.

Новая версия должна иметь тег `v0.8.0` и файл `RelayDesk-Setup-0.8.0-x64.exe`. Три числа версии в теге, проекте и имени установщика должны совпадать. Текст GitHub Release используется как патчноут. Приложение проверяет размер и SHA-256 из метаданных GitHub; контрольная сумма не заменяет подпись издателя.

Для публикации:

1. Увеличь `Version` в `RelayDesk.csproj`. Версия в окне и журнале обновится автоматически.
2. Подготовь файл с кратким списком изменений.
3. Задай `GH_TOKEN` в окружении текущего процесса. Нужен доступ Contents: write к выбранному репозиторию. Не сохраняй токен в исходниках или настройках приложения.
4. Запусти `powershell -NoProfile -ExecutionPolicy Bypass -File .\Publish-Release.ps1 -Repository владелец/репозиторий -NotesFile .\release-notes-0.8.0.md`.

Команда собирает установщик, встраивает адрес репозитория для будущих установок, загружает EXE и SHA-256 в черновик релиза. Публикация выполняется с параметром `-Publish` или вручную на GitHub. Опубликованные версии не перезаписываются: для исправления выпускается следующая версия.

Когда пользователь нажимает «Установить», приложение показывает описание и предупреждение об остановке VPN. Загрузка идёт при работающем подключении. Только после проверки файла RelayDesk закрывается, помощник повторно проверяет SHA-256, запускает установщик и затем открывает установленное приложение. Ошибка загрузки не отключает VPN. Результат установки записывается в `%LOCALAPPDATA%\RelayDesk\application-update-status.txt`.

Версии 0.7.0 и старше не умеют обновлять само приложение: переход на 0.8.0 нужно выполнить её установщиком. Следующие выпуски можно ставить кнопкой в приложении.
