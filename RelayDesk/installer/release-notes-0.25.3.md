# RelayDesk 0.25.3

- Во вкладке «Соединения» добавлены отдельные фильтры приложения, назначения, типа, маршрута и сработавшего правила. Фильтры работают совместно с общим поиском. Сброс фильтров не снимает выделение.
- Нажатие заголовка сортирует столбец; повторное нажатие меняет направление. Порядок сохраняется при обновлении списка.
- Ctrl + щелчок добавляет или убирает соединение из выделения. Выделение привязано к ID соединения и сохраняется при сортировке и фильтрации. Закрытые соединения снимаются с выделения.
- Кнопка «Настроить выбранные…» открывает общий предпросмотр правил: для приложений, точных доменов / IP или доменов с поддоменами. Можно назначить VPN, zapret или прямое подключение. Повторяющиеся цели объединяются.
- Совпадающие правила обновляются, новые ставятся выше остальных. При отсутствии нужных данных ядра или ошибке проверки пакет не сохраняется частично.

Сохранение правил не меняет текущие соединения. Для их применения к работающему профилю нажми «Применить правила»: профиль переподключится. Ограничения ядра сохраняются: правила приложений требуют sing-box с TUN; Xray поддерживает правила адресов, mihomo настраивается через исходную конфигурацию.
