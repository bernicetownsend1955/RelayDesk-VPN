RelayDesk 0.15.0

- Исправлен запуск профилей Xray из подписок при включённом zapret: к ним больше не добавляются правила EXE в формате sing-box. Discord разделяется по доменам и указанным IP голоса. Правила EXE и TUN требуют профиля sing-box.
- Новые профили Xray из подписок включают системный HTTP-прокси. Для ранее импортированных профилей без системного прокси на главной доступна кнопка его включения.
- Профили вынесены на отдельную страницу: список на всю высоту, поиск по названию, серверу и ядру, фильтр групп. В боковой панели осталась краткая информация о выбранном профиле.
- Добавление профиля, файла и подписки собрано в меню «Добавить». Перенос в группу доступен через контекстное меню профиля. Двойной щелчок открывает панель подключения.

Все четыре ядра по-прежнему включены в установщик. Обновление не запускает подключение автоматически.
