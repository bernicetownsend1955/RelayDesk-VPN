# RelayDesk 0.28.0

- На главной появились пресеты «По правилам», «Всё напрямую» и «Всё через VPN» для sing-box и Xray.
- Пресеты действуют на все профили и не удаляют сохранённые правила. При работающем VPN смена пресета переподключает его; при выключенном — сохраняется до следующего подключения.
- DNS sing-box в прямом пресете направляется напрямую, в пресете VPN — через выбранный выход с отдельным системным разрешением адреса самого VPN-сервера.
- У VPN и zapret теперь по одной кнопке: небольшая иконка и действие внутри кнопки. Дублирующая кнопка под круглым значком удалена.
- Ctrl+A в таблице соединений выделяет все видимые активные соединения с учётом фильтров. В текстовых полях сочетание выделяет текст.
- Для подключений без совпавшего правила можно выбрать общий маршрут: исходный профиль, VPN, напрямую или zapret. Выбор сохраняется для всех профилей и групп; пресеты временно перекрывают его.
- Состояние включения отличается заливкой и иконкой; запущенное ядро по-прежнему проверяется отдельно от доступности сети.
